# FluxPay: Subscriptions & Billing Made Simple 💳✨

FluxPay is a modern, responsive, single-file web application designed to manage plans, users, and subscriptions with a beautiful, production-ready interface. It includes client-side routing, runtime data, and custom confirmations to provide a seamless experience for both administrators and end-users.

---

## ✨ Features

-   **Admin Dashboard:** Comprehensive overview of active plans, subscriptions, and total users.
-   **User Dashboard:** Personalized view for users to manage their current plan, status, and recent billing history.
-   **Secure Login:** Separate login portals for users and administrators.
-   **Plan Management:** Create, update, and delete subscription plans (Admin).
-   **Subscription Management:** Overview and management of all subscriptions (Admin).
-   **User Management:** View and manage all registered users (Admin).
-   **Client-side Routing:** Fast and fluid navigation without full page reloads.
-   **Responsive Design:** Optimized for various screen sizes.

## ⚙️ Installation & Setup

To get FluxPay up and running on your local machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Ganeshkaithoju/hackathon.git
    cd FluxPay
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    # or yarn install
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    # or yarn dev
    ```
    This will typically start the application on `http://localhost:3000` (or similar).

4.  **Build for production (optional):**
    ```bash
    npm run build
    # or yarn build
    ```
    This command will create a production-ready build of your application.
